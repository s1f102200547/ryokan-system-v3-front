# T4: Session Cookie のコピー

脅威の説明と方針は `docs/Security/SecurityPolicy.md` の T4 を参照（方針: 受容）。

## 受容の前提として効いている点

- セッションは当日 23:00 で切れる（`src/app/api/auth/login/route.ts` の `msUntilToday23JST`）。この期限は延ばさない。
- `HttpOnly` と `SameSite=Strict` を付けている。
- 紛失時は、Firebase でアカウントを無効にすれば次の API 呼び出しから 401 になる（`verifySessionCookie(cookie, true)` で毎回失効を確認しているため）。

## 対策

追加の対策はしない。Cookie を PC のハードウェアに結び付ける対策（DBSC）は保留する（`Rejected.md`）。
