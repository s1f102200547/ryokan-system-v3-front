# タイムテーブル仕様書

## 概要

宿泊施設の当日ゲスト情報・スケジュールを一覧表示するスタッフ向け機能。印刷対応。

## API

### GET /api/timetable

**認証:** Cookie `session` 必須

| パラメータ | 型 | 必須 | 説明 |
|---|---|---|---|
| `date` | string | ✓ | `YYYY-MM-DD` 形式の対象日付 |

**エラー:** `401` 認証失敗 / `400` パラメータ不正 / `503` Firestore 接続不可 / `500` その他

---

## セクション仕様

### 1. CheckInTime（チェックイン時刻）
- **列:** 15:00〜21:00（1時間刻み）+ その他
- **対象:** 当日チェックイン予約（`check_in_date === targetDate`）

### 2. OpenAirBathEvening（夕方露天風呂）
- **列:** 16:00〜22:00（1時間刻み、7列）
- **対象:** 当日滞在中ゲストの `open_air_bath_time[idx]`(連泊想定)

### 3. Dinner（夕食）
- **列:** 17:30 / 18:00 / 18:30 / 19:00 / 19:30 / 20:00 / 未定
- **対象:** 当日滞在中ゲストの `dinner_time[idx]`
- **除外:** `'NONE'` / `'CANCEL'`

### 4. GuestInfo（在泊情報）
- **対象:** 全7部屋
- **表示:** `timetable_info[idx]` の値。空室は `'空室'`

### 5. BreakfastHeader + Breakfast（朝食）
- **翌日日付ラベル:** `M/D` 形式
- **列:** 7:30 / 8:00 / 8:30 / 9:00 / 9:30（5列 × 上段a / 下段b）
- **場所:**

  | キー | 場所 |
  |---|---|
  | `7:30a` / `8:00a` / `9:00a` | ラウンジ |
  | `8:30a` / `9:30a` | 53号室 |
  | `7:30b` / `8:00b` / `9:00b` | ラウンジ |
  | `8:30b` / `9:30b` | 54号室 |

- **セル内容:** `{場所ラベル}` / `Room: {部屋マーク}　menu:　×`(×の後に人数を書く想定)

### 6. CheckoutNotice（チェックアウト通知）
- **対象:** 翌日 `isTodayCheckout` の部屋（`nextDay` 基準）

### 7. OpenAirBathMorning（朝露天風呂）
- **列:** 7:30 / 8:00 / 8:30 / 9:00 / 9:30（5列）
- **対象:** 当日滞在中ゲストの `open_air_bath_time[idx]`

### 8. CheckoutTime（チェックアウト時刻）
- **列:** 7:30 / 8:00 / 8:30 / 9:00 / 9:30 / 11:00（6列）
- **対象:** 翌日 `isLateCheckout` の部屋（11:00 列のみ部屋マーク表示）

### 9. NumberOfBreakfast（朝食人数）
- 静的フォーム（手書き用途、データ取得なし）
